# Phantom Wallet PWA

A mobile-first Progressive Web App with the Phantom wallet logo. Add it to your phone home screen to open it like a native app.

## Run locally

```bash
cd phantom
npm install
npm run dev
```

Open http://localhost:5175 on your phone (same Wi‑Fi) or use Chrome DevTools mobile emulation.

## Build

```bash
npm run build
npm run preview
```

## Add to Home Screen

- **Android (Chrome):** Tap **Add Phantom to Home Screen** when prompted, or use the browser menu → Install app.
- **iPhone (Safari):** Share → **Add to Home Screen** → Add.

The home screen icon uses the purple Phantom ghost logo.
